# Meow! Nyon! Ulelelelelelele!  

Ладно, это проектик по квадратке  

Данный проект решает заданные пользователем квадратные уравнения.  

Используются языки C/C++  

Рекомендуется использовать компилятор g++ версии 16.1 и новее  

Скачиваете все файлы, кладёте в одну папку, в консоли пишите g++ C:\\<путь до папки>\main.cpp -o nyon  

Программу можно запустить запускать следующими способами:  

**.\main.cpp --help**  
Покажет мини-справку о данной программе, покажет доступные флаги и предложит решить квадратное уравнение с вашими коэффициентами  

**.\main.cpp**  
Предлагает решить введённые вами квадратные трёхчлены  

**.\main.cpp --tests rand_tests_count**  
Запускает тестирование решений квадратных уравнений из:  
- стандартных тестов (они записаны в tests.txt)  
    (P.S. вы можете добавить туда и свои тесты, изменив количество тестов и добавив коэффициенты, кол-во корней (число от 0 до 2 или 3 если корней бесконечно много) и сами корни);  
- случайных тестов (указываете их количество в необязательном параметре флага "rand_tests_count", по умолчанию равном нулю).
